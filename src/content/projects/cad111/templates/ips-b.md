My sheet template for B-size drawings in the IPS (inch-pound-second) unit system. It uses the same title block as the
[A-size template](/cad111/templates/ips-a), on a sheet with room for more views or a larger scale.

## Sheet
| | |
| --- | --- |
| Size | B, 17 × 11 in, landscape |
| Units | Inches (IPS) |
| Zones | 1–4 across, A–B down |
| Projection | Third angle (symbol in the title block) |
| Sheets | 1 of 1 |
| Software | SolidWorks |

## Title block
| Area | What it holds |
| --- | --- |
| Header | Bristol Community College, with my DN logo |
| Drawing info | Title, size, drawing number, revision, scale, weight, sheet number |
| Sign-off | Drawn, engineering approval, and manufacturing approval, each with a name and date |
| Tolerances | Unless otherwise specified: dimensions in inches; fractional ±1/64, angular ±1°, two-place decimal ±.01, three-place decimal ±.005 |
| Standard | Geometric tolerancing interpreted per ANSI Y14.5 |
| Part info | Material and finish |
| Note | Do not scale drawing |

## Revision block
Zone, revision, description, date, and approval columns, ready for the first revision.
